# Our Love Story — как запустить

## Что внутри

```
index.html              страница сайта
manifest.webmanifest    чтобы сайт можно было «установить» на телефон как приложение
css/style.css           весь дизайн (компьютер + телефон)
js/config.js            адрес базы и публичный ключ
js/api.js               связь с Supabase (вход, записи, фото, смена почты/пароля)
js/images.js            сжатие и загрузка фото
js/ui.js                окна, сообщения, просмотр фото
js/posts.js             раздел Notes (карусель и пост целиком)
js/gallery.js           раздел Gallery
js/timeline.js          раздел Timeline
js/app.js               вход, меню профиля, аккаунт, переключение разделов
img/                    иконки и фоны
```

## Фоны

Картинки лежат в папке `img/`. Для каждого экрана сайт берёт первую найденную:

| экран | что пробует по порядку |
|---|---|
| главная и вход | `main.jpg` |
| Notes | `background.jpg` → `2025.jpg` (фон выбранного года) → `main.jpg` |
| Gallery | `background.jpg` → `gallery_main.jpg` → `main.jpg` |
| Timeline | `background.jpg` → `timeline.jpg` → `main.jpg` |

На телефоне для каждого имени сначала пробуется версия `_mobile` (например `main_mobile.jpg`).
Чтобы во всех разделах был один общий фон, как в последнем дизайне, просто положи в `img/` файл `background.jpg`
(и при желании `background_mobile.jpg`).

## Пользователи (панель Supabase)

1. **Authentication → Sign In / Providers** → выключи **Allow new users to sign up**.
2. **Authentication → Users → Add user → Create new user**: почта, пароль, галочка **Auto Confirm User**.
3. Новый аккаунт нужно добавить в участники сайта (это делает Claude). Пока аккаунт не добавлен, сайт пустит, но скажет, что аккаунт не участник.

## Как устроена защита

- Читать и менять записи и фото могут только аккаунты из таблицы `members`.
- Фото лежат в закрытом хранилище, страница получает на них временные ссылки (живут сутки).
- Ключ в `js/config.js` публичный — так задумано в Supabase; секретов в коде нет.
- Раз в сутки база сама отправляет себе запрос, чтобы бесплатный проект не замораживался.
